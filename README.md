# Networking for Application Security Engineers

Follow a shipment dashboard request from the browser through DNS, TLS, a CDN, and a private API. The 19 chapters use packet traces, HTTP exchanges, and local exercises to show where access decisions happen and how to diagnose a failed request.

Start with the [course checklist](appsec-networking-checklist.md) for the chapter sequence and lab requirements, or open [chapter 01](01-network-layers-and-devices.md) to begin. Each chapter links to the next and supplies its own exercise data. Finish with the [practical self-check](appsec-networking-checklist.md#a-practical-self-check).
